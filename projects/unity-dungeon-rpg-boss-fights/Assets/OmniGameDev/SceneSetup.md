# Unity Scene Setup

1. Create a new Unity 3D project.
2. Copy the `Assets` folder from this generated project into the Unity project.
3. Add a floor, walls, a capsule player with `CharacterController` and `PlayerController`, and cube enemies with `EnemyAI`.
4. Add `OmniGameManager` to an empty scene object and assign the player and enemies.
5. Press Play.
